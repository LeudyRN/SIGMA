Claves para la lectura

PK identifica la clave primaria; FK Rxx, la relación del catálogo; U1/U2, una restricción única. 1 significa exactamente uno; 0..1, opcional y único; 0..N, ninguno o varios. Las claves compuestas comparten el mismo identificador. Consulta la guía para la notación completa y las instrucciones de impresión.
